# Minimarket – C# .NET (Windows Forms)

Proyecto base funcional para el TP de PPV.
Incluye:
- CRUD de Productos
- Ventas (carrito) con descuento automático de stock
- Reporte simple de ventas
- Script SQL para SQL Server Express / LocalDB

## Requisitos
- Visual Studio 2022+
- .NET 6 SDK
- SQL Server Express o LocalDB
- Restaurar paquetes NuGet si VS lo solicita (System.Data.SqlClient)

## Configurar conexión
Editar `Config.cs` y ajustar la cadena de conexión según su entorno.
